# 성남지역 고등학교 선택과목 가이드

2022 개정교육과정 · 학교별 편제표 · 대학별 권장과목

성남지역 고등학교의 2027학년도 입학생 교육과정 편성표와, 대학 전공별 권장·핵심 과목을 한눈에 확인하는 웹앱입니다.
자료는 각 학교 교육과정 편성표, 학과바이들(캠퍼스멘토), 각 시도교육청, 대학 권장과목 내용을 바탕으로 제작되었습니다.

- 제작: 숭신고등학교 진로전담교사 김강석

## 주요 기능

- 학교별 교육과정 편제표 조회 및 학교 간 비교
- 대학 전공별 권장·핵심 과목 표시와 대학별 지정 현황 확인
- 과목 선택·해지 및 일반고 이수 학점 규정 자동 판별
- 2·3학년 수강 신청 계획서 PDF 다운로드

## 로컬 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # dist/ 에 정적 파일 생성
```

## GitHub Pages 배포

1. 저장소에 push (기본 브랜치 `main`)
2. 저장소 **Settings → Pages → Source** 를 **GitHub Actions** 로 설정
3. `.github/workflows/deploy.yml` 이 자동으로 빌드·배포합니다.

## 저작권 및 이용 안내

- **저작권자**: 숭신고등학교 진로전담교사 김강석
- **이용 범위**: 본 자료는 중·고등학교 교사의 수업 및 지도 목적으로만 사용할 수 있습니다.
- **금지 사항**: 학생·학부모 등 교사를 제외한 타인에게의 무단 배포 및 상업적 이용을 엄격히 금합니다.
